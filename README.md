# Ciclo Preparatório Lighthouse

Este repositório documenta meu aprendizado durante o Ciclo Preparatório do programa Lighthouse, da Indicium AI. Os conteúdos estão organizados por módulo e reúnem anotações, exercícios, exemplos apresentados nas aulas e reflexões sobre os temas estudados.

## Objetivo

Registrar minha evolução ao longo do ciclo, consolidar os conhecimentos por meio da prática e manter um histórico organizado dos estudos realizados.

## Organização do repositório

Cada módulo possui sua própria pasta. Conforme o conteúdo estudado, os diretórios podem incluir:

- `README.md` com a visão geral do módulo;
- `anotacoes/` com sínteses dos conceitos;
- `exercicios/` ou `pratica/` com atividades realizadas;
- `exemplos_da_aula/` com códigos apresentados durante as explicações.

## Sobre este material

Este é um registro pessoal de aprendizagem. Os conteúdos foram sintetizados e organizados a partir das aulas do Ciclo Preparatório Lighthouse. Os materiais didáticos originais pertencem aos respectivos professores e à Indicium AI, sem reivindicação de autoria sobre os exemplos apresentados.
