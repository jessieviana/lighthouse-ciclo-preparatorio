# Reflexão sobre Engenharia de Dados

Este módulo reforçou por que me identifico com Engenharia de Dados. Gosto de compreender como as informações saem das fontes, atravessam diferentes etapas e chegam organizadas para análise e tomada de decisão.

Durante meus estudos, já tive contato com partes desse processo ao trabalhar com Python, SQL, bancos de dados, APIs, serviços de nuvem e controle de versão. A aula me ajudou a enxergar essas ferramentas como componentes de uma plataforma, e não como conhecimentos isolados.

Também compreendi que construir um pipeline não significa apenas fazê-lo executar. É necessário pensar em frequência, volume, dependências, falhas, segurança, custos, qualidade e valor para o negócio. A escolha entre batch e streaming ou entre ETL e ELT deve partir dos requisitos do projeto.

Quero continuar desenvolvendo principalmente:

- modelagem e transformação de dados;
- construção de pipelines reproduzíveis;
- orquestração e monitoramento;
- serviços de dados em nuvem;
- qualidade, segurança e governança.

Para mim, Engenharia de Dados é a construção da base que permite transformar dados em conhecimento confiável. Esta reflexão é autoral e representa o que compreendi ao revisar a Aula 10 do Ciclo Preparatório Lighthouse.
