# Fundamentos de Engenharia de Dados

A Engenharia de Dados sustenta a plataforma que permite coletar, armazenar, transformar e disponibilizar dados para análises, produtos e decisões de negócio.

## Principais responsabilidades

- **Coleta:** integrar dados provenientes de APIs, bancos, arquivos e streams com qualidade e rastreabilidade.
- **Armazenamento:** definir modelos e camadas para dados brutos e tratados em ambientes como Data Lakes e Data Warehouses.
- **Processamento:** construir fluxos para transformar e consolidar dados em lote ou em tempo real.
- **Orquestração e automação:** agendar tarefas, acompanhar execuções e tratar falhas.
- **Governança e segurança:** aplicar catálogo, linhagem, schemas, controles de acesso e requisitos de conformidade.

O objetivo não é apenas movimentar informações. A plataforma precisa entregar dados confiáveis e utilizáveis para Analytics Engineers, analistas, cientistas de dados e outras áreas consumidoras.

## Visão de plataforma

Uma plataforma de dados pode reunir diferentes etapas:

1. fontes e ingestão;
2. armazenamento;
3. transformação e modelagem;
4. orquestração e implantação;
5. consumo analítico, Business Intelligence e Machine Learning.

O engenheiro de dados trabalha principalmente na integração entre essas etapas, considerando escalabilidade, observabilidade, segurança e valor para o negócio.
