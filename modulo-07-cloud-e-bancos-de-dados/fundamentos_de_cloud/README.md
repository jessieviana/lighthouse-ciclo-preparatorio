# Aula 08 - Fundamentos de Cloud

Esta seção registra meu aprendizado sobre computação em nuvem no Módulo 07 do Ciclo Preparatório Lighthouse.

## Conteúdos estudados

- conceitos e características da computação em nuvem;
- modelos de serviço IaaS, PaaS e SaaS;
- escalabilidade e elasticidade;
- principais provedores de nuvem;
- critérios técnicos e de negócio para escolha de serviços;
- segurança, responsabilidade compartilhada e controle de custos.
