# Reflexão sobre cloud na minha trajetória

Eu já havia estudado AWS e conquistado as certificações Cloud Practitioner e Developer - Associate antes de organizar este módulo. A aula de Fundamentos de Cloud me ajudou a colocar esse conhecimento dentro de uma visão mais ampla, considerando também outros provedores e os critérios utilizados em decisões de arquitetura.

Um ponto importante foi compreender que conhecer muitos nomes de serviços não é o mesmo que saber escolher. A decisão depende do projeto, dos dados, do orçamento, da segurança, das integrações e da experiência da equipe.

## Conexões com minhas práticas

No desenvolvimento de um chatbot para WhatsApp, utilizei o Google Cloud Run para disponibilizar uma aplicação em contêiner. Essa experiência me mostrou na prática alguns benefícios de um serviço gerenciado: consegui publicar a aplicação sem administrar diretamente um servidor, mas continuei responsável pelo código, variáveis de ambiente, autenticação, logs e custos.

Nos estudos de AWS, trabalhei com conceitos de identidade, computação, armazenamento, aplicações serverless, monitoramento e integração entre serviços. Ao comparar essa experiência com outros provedores, percebi que os nomes mudam, mas muitos fundamentos permanecem.

## O que pretendo desenvolver

- melhorar minha capacidade de traduzir requisitos em decisões técnicas;
- comparar serviços equivalentes entre provedores sem escolher apenas por familiaridade;
- aprofundar conhecimentos de cloud aplicados à engenharia de dados;
- considerar segurança, observabilidade e custos desde o início dos projetos;
- fortalecer meu inglês técnico, importante para documentação e projetos internacionais.

## Aprendizado principal

Minha especialização em AWS é uma base importante, mas não deve limitar minha visão. Entender os fundamentos de cloud e conhecer o básico de diferentes provedores amplia minha capacidade de analisar cenários e escolher soluções adequadas para cada projeto.
