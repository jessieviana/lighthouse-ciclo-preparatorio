# Aula 09 - Fundamentos de Bancos de Dados

Esta seção reúne minhas anotações e reflexões sobre fundamentos de bancos de dados e conceitos de modelagem estudados no Módulo 07 do Ciclo Preparatório Lighthouse.

## Conteúdos estudados

- banco de dados e Sistema Gerenciador de Banco de Dados (SGBD);
- dados estruturados, semiestruturados e não estruturados;
- arquitetura em camadas e independência de dados;
- propriedades ACID e transações;
- bancos relacionais e NoSQL;
- tabelas, registros, campos, chaves, restrições e índices;
- categorias da linguagem SQL;
- diferenças entre OLTP e OLAP;
- Data Warehouses e armazenamento em linhas ou colunas;
- modelo entidade-relacionamento, normalização, Star Schema e Snowflake Schema.
