# Módulo 05 - Fundamentos de Controle de Versão

Este diretório documenta meu aprendizado sobre terminal, Git, GitHub e GitFlow
no Ciclo Preparatório Lighthouse, da Indicium AI.

Além das anotações conceituais, a pasta `pratica/` registra como apliquei o
fluxo de versionamento neste próprio repositório. Assim, o histórico de
branches, commits e pull requests funciona como evidência da prática.

## Conteúdos estudados

- terminal, shell, CLI e GUI;
- comandos básicos de terminal;
- repositórios locais e remotos;
- branches, commits e staging area;
- clone, fork e pull request;
- GitFlow;
- comandos Git usados no dia a dia;
- finalidade do `.gitignore`.

## Estrutura

| Caminho | Conteúdo |
|---|---|
| `anotacoes/terminal_e_shell.md` | Conceitos e comandos básicos de terminal |
| `anotacoes/conceitos_git.md` | Repositório, branch, commit, PR, clone, fork e GitFlow |
| `anotacoes/comandos_git.md` | Comandos praticados e cuidados importantes |
| `pratica/aplicacao_gitflow.md` | Fluxo aplicado neste repositório |
