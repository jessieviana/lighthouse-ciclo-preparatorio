# Terminal e shell

O terminal é o programa pelo qual interagimos com o computador usando texto. O
shell interpreta os comandos e faz a comunicação com o sistema operacional.

No Windows, utilizei principalmente o PowerShell integrado ao VS Code. O Bash é
muito comum em sistemas Linux e também pode ser usado no Windows por ferramentas
como Git Bash e WSL.

## Comandos básicos

| Comando | Finalidade |
|---|---|
| `ls` | Listar arquivos e diretórios |
| `cd caminho` | Entrar em outro diretório |
| `pwd` | Mostrar o diretório atual |
| `mkdir nome` | Criar um diretório |
| `rmdir nome` | Remover um diretório vazio |
| `cp origem destino` | Copiar arquivos ou diretórios |
| `mv origem destino` | Mover ou renomear |
| `cat arquivo` | Exibir o conteúdo de um arquivo |
| `history` | Consultar o histórico de comandos |

Alguns comandos podem apagar ou sobrescrever dados. Antes de executar ações como
remoções recursivas, é importante confirmar o caminho e manter uma cópia quando
o conteúdo for relevante.
